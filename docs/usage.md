# 使い方

## 太陽系
「再生」で開始、「一時停止」で止める。「リセット」は経過時間と軌跡を初期化します。時間速度は0.02〜2年/秒。月の周期は1〜12か月、初期値は3か月です。表示対象を絞り込めます。地球・月ズームでは対象と軌跡の選択は無効になります。天体を押すか説明メニューを選ぶと情報を表示します。タブ非表示やブラウザ非表示中は経過時間が進みません。

## 増加のしくみ
初期値0〜1兆、増加率0〜50%、期間1〜30期を指定します。各期の値は「初期値 × (1 + 増加率)^期数」です。初期値0は増加せず、倍率は表示しません。不正入力はメッセージで通知します。

## ピアノ
鍵盤操作でWeb Audioを有効化します。白鍵・黒鍵を含む12鍵。音程異常、ノイズ、両方を選べます。演奏の強さが大きいほど摩耗し、ダメージ100%で発音しません。修理で摩耗と演奏回数が0に戻ります。音量0%はミュート、演奏強度0%は無音で摩耗もしません。

ショートカットはピアノタブで入力欄にフォーカスしていないときに使えます。タブは左右矢印・Home・Endでも切り替えられます。

## 困ったとき
音が出ない場合は鍵盤を一度押し、サイト・端末・ブラウザのミュートを確認します。音声を有効化できなければ通知を表示します。狭い画面では操作パネルは下に並びます。更新は再読み込みで反映します。
