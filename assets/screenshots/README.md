# 公開サイトのスクリーンショット

READMEのアプリ紹介に使用する、加工していないスクリーンショットの元素材です。

- 撮影元: https://kentarooishi-collab.github.io/simulation-lab/
- 撮影日: 2026-10-05（日本時間）
- 撮影方法: デスクトップブラウザで各タブの初期状態を全ページ撮影
- 形式: JPEG

| ファイル | アプリ | 撮影時の状態 |
| --- | --- | --- |
| `solar-system.jpg` | 太陽系を旅する | 太陽系全体、時間の速さ0.10年/秒、月周期3か月、一時停止 |
| `growth.jpg` | 増加のしくみ | 初期値100、増加率10%、期間12期 |
| `piano.jpg` | 音とピアノ | 演奏の強さ55%、耐久度100%、音量40%、演奏前 |

画面が変わった場合は、公開サイトで各タブを選び、対応する画像を撮り直してください。画像リンクはいずれも公開サイトを開きます。アプリの選択はサイト上部のタブで行います。
